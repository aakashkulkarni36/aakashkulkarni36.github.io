JAAABS

Job Application Automator & Aakash's Bot Studio

Manually applying at scale is slow, repetitive, and easy to get wrong. JAAABS discovers companies, scores roles against a binding fact bank, tailors a LaTeX resume per position, autofills applications in Chromium, and pauses at every risky step — login, CAPTCHA, OTP, review, submit.

02 — Research2025

HeteroBugDetect

Bugs that only appear on GPU versus CPU are invisible to ordinary tests. HeteroBugDetect combines grammar-based kernel-sensitive fuzzing, differential testing across hardware, and LLM triage to separate real bugs from noise.

ProblemPlatform-specific bugs only show up on GPU vs CPU, so normal tests miss them.
SolutionGrammar-based kernel-sensitive fuzzing + differential testing + LLM triage.
EngineeringKernel-aware input generation, differential harness, false-positive filtering.

04 — Motion2026

The Lazy Radical

Motion graphics tools are manual, expensive, and non-deterministic. The Lazy Radical is a deterministic 4K pipeline: scenes are declarative HTML/CSS, Playwright frame-steps them with 180° shutter motion blur, and FFmpeg stitches and masters. No timeline editing.

ProblemMotion graphics are manual, expensive, and non-deterministic.
SolutionA deterministic 4K pipeline: HTML/CSS scenes, Playwright frame-stepping, FFmpeg stitching.
EngineeringFrame-accurate rendering, reproducible builds, and versioned scenes.

IEEE AIxSE 2025 · Co-authored

LLM-Guided Differential Fuzzing for Detecting Platform-Specific Bugs in Scientific Applications

Heterogeneous bugs appear when scientific software runs on different hardware. HeteroBugDetect combines grammar-based kernel-sensitive fuzzing with differential testing and LLM triage. On LAMMPS, it found 8 of 20 known bugs and 2 previously unknown bugs.
